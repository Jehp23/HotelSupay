Coloca aquí las imágenes del hotel (fotos de habitaciones, spa, gastronomía, etc.).

- Ruta pública: `/images/<archivo>`
- Ejemplo de uso en React:
  `<img src="/images/habitacion-1.jpg" alt="Habitación" />`

Sugerencias de organización:
- `rooms/`
- `spa/`
- `gastronomia/`
- `experiencias/`
- `brand/` (logo, variantes)
